# Annabelle Klosterman | Scholarship Guidance

A one-page website for local scholarship consultations, workshops, and classes.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub Pages will publish `index.html` and the `assets` folder.

The site is plain HTML, CSS, and JavaScript. No build step is required.
